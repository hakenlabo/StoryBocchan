# ストーリー坊ちゃん

アニメーションのプリプロ（企画 → 構成 → ラフ絵 → 尺 → Vコンテ）を、ひとつの画面でつなげて進めるためのアプリです。
ポストイットのようにカードを貼ったり剥がしたりしながら、アイデアを育てていきます。

> マップ・箇条書き・タイムライン・描画・Vコンテ再生・カメラワーク・ファイル保存まで使えます。MP4／PDFの書き出しは順次追加されます。

---

## はじめて使うとき（clone）

インストールは不要です。ブラウザ（Chrome または Safari）だけで動きます。

1. ターミナル（Windowsは「Git Bash」など）を開いて、置きたい場所で次を実行します。

   ```bash
   git clone <このリポジトリのURL>
   ```

2. できたフォルダの中の **`index.html` をダブルクリック** してブラウザで開きます。
   （Chromeにドラッグ＆ドロップしてもOK）

iPadの場合は、先生が公開しているWebページ（GitHub Pages）のURLをSafariで開いてください。

## 更新するとき（pull）

先生から「更新しました」と連絡があったら、フォルダの中で次を実行します。

```bash
git pull
```

そのあとブラウザで index.html を開き直す（または再読み込みする）と新しくなります。
**作品のデータはこのフォルダの中には入っていない** ので、pullしても作品は消えません。

## 取り消し・やり直し

- **⌘Z**（WindowsはCtrl+Z）で取り消し、**⌘⇧Z**（Ctrl+Shift+Z）でやり直し。画面上の **↶ ↷** ボタンでもできます。
- カードを動かす、作る、剥がす、タイムラインに並べる、尺やカメラを変える、整列する…など、ほとんどの操作を戻せます。
- 文字を入力している途中の⌘Zは、文字だけの取り消しです。描画パネルの中では絵の取り消しです。

## 使い方（箇条書き）

企画の最初は「箇条書き」タブで、思いついたことをどんどん書き出すのがおすすめです。
**1行が1枚のカード** になり、そのままマップにも出ます。

| やりたいこと | 操作 |
|---|---|
| 次の行を書く | Enter（いちばん下の「＋」の行なら、Enterを押すたびにカードが増えます） |
| 子にする（字下げ） | Tab、または「字下げ →」 |
| 戻す（字上げ） | Shift+Tab、または「← 字上げ」 |
| 並べ替え | ⌥（Alt）+↑↓、または ↑ ↓ ボタン |
| 行を消す | 空の行で Backspace |
| まとめて入れる | メモ帳などの箇条書きを貼り付けると、字下げごと行になります |
| 行ごとコピー・切り取り | 文字を選ばずに ⌘C／⌘X（またはボタン）。子の行も一緒です。⌘V（「貼り付け」）で今の行の下に入ります |

## 使い方（マップ画面）

| やりたいこと | 操作 |
|---|---|
| カードを作る | 何もない所を **ダブルクリック**（iPadはダブルタップ）、または「＋ カード」 |
| 文字を書く・直す | カードを **ダブルクリック**（または選んで Enter）。Enterで確定、Shift+Enterで改行 |
| 動かす | カードをドラッグ。親カードを動かすと子カードもついてきます |
| 親子にする | カードを **別のカードに重ねて離す** と、その子になります |
| 子カードを足す | カードを選んで **Tab**、または「＋ 子カード」 |
| 複数選ぶ | **Shift＋クリック**（iPadは「☑ 複数選択」を押してからタップ）。選んだ順に①②③と番号が付きます |
| 選んだ順にタイムラインへ | 複数選んだカードのどれかを下の帯へドラッグ。**選んだ順に** まとめて並びます |
| 次のカードを足す | **⌘+Enter**（WindowsはCtrl+Enter）。選んでいるカードの下に兄弟として作ります。文字を入力中でもOK |
| 親子を切り離す | 親子をつなぐ **線をクリック**（タップ） |
| コピー・切り取り・貼り付け | ⌘C／⌘X／⌘V（WindowsはCtrl）、またはボタン。子カードごとコピーされ、選んでいるカードの子として貼り付きます。切り取ったカードは保留トレイにも入ります |
| 剥がす（保留にする） | カードを選んで「剥がす」ボタン、Delete キー、または右の **保留トレイへドラッグ** |
| 戻す | 保留トレイの「戻す」（元の場所へ）、またはトレイからマップへドラッグ |
| 本当に消す | 保留トレイの「削除」（ひとつずつ）か「全部削除」。消してもすぐなら ⌘Z で戻せます |
| 画面を動かす | 何もない所をドラッグ／トラックパッドの2本指スクロール |
| 拡大・縮小 | ピンチ、⌘(Ctrl)+ホイール、ツールバーの －／＋。「全体表示」で全部が見える位置へ |
| きれいに並べる | **L** キー、または「⊞ 整列」→「ツリーに整列」（親の右に子）。⌘Zや「元に戻す」で戻せます |
| グリッドに合わせる | **G** キー、または「⊞ 整列」→「グリッドに吸着」。動かしたカードが背景の点にそろいます |

## シーン

カットが増えると管理が大変なので、**マップのツリー1本を1つのシーン** として扱います。

- いちばん上のカード（例「シーン1 朝」）の下に、カットのカードを子としてつなげてください。そのツリーが1つのシーンになります。
- マップでカードを選ぶと、下のタイムラインがそのカードのシーンに切り替わります（見出しのプルダウンでも選べます）。
- カット番号（#1, #2…）はシーンごとに数えます。
- どのツリーにも入っていないカードは「ツリーに入っていないカード」というシーンにまとまります。
- Vコンテの画面の右の **「シーン構成」** で、流すシーンにチェックを入れ、↑↓で順番を決めます。

## 使い方（タイムライン）

画面の下の帯がタイムラインです。上の「タイムライン」タブを押すと大きく表示できます。

| やりたいこと | 操作 |
|---|---|
| 採用する | マップのカードを **下の帯へドラッグ**。青い線の位置に入ります |
| 並べ替える | 帯の中でカードをドラッグ |
| 尺を変える | カードの **右端をドラッグ**、または尺の数字（例 `3+0`）をタップして入力 |
| 外す | カードの「×」、またはマップへドラッグ（カード自体は消えません） |
| 同じカードをもう一度使う | 並べ済みのカードをもう一度帯へドラッグ。「連動して並べる」か「コピーして並べる」かを選べます |

- **連動**：絵と文字は共通です。どちらかを描き直すと両方変わります（尺は別々）。タイムラインでは点線の枠と🔗が付きます。
- **コピー**：複製を作って並べます。あとで別々に描き直せます。

- 尺は **「秒+コマ」** で書きます。`2+12` は「2秒と12コマ」（24fpsなら60コマ）。`3` だけなら3秒です。
- 入力中は ↑↓ で1コマずつ、Shift+↑↓ で1秒ずつ変えられます。
- 総尺は帯の左上に常に出ています。
- fps（24/30）を途中で変えると、秒数が変わらないように尺が換算されます。

## 使い方（絵を描く）

| やりたいこと | 操作 |
|---|---|
| 描画パネルを開く | カードの **絵の部分（灰色の枠）をダブルクリック**、タイムラインのカードをダブルクリック、またはカードを選んで「✎ 描く」 |
| 描く | ペン・指・マウスで描けます。Apple Pencilは筆圧で太さが変わります |
| 色・太さ | 黒・赤・青、細・中・太 |
| 消す | 「消しゴム」でこすった所が消えます |
| 間違えた | 「↶ 取り消し」（⌘/Ctrl+Z）、「↷ やり直し」 |
| 前後のカットへ | ◀ ▶（←→キー）。タイムラインに採用したカードだけ |
| 閉じる | 「完了」または Esc |
| 内容・セリフを書く | 描画パネルの下の「内容」「セリフ・メモ（SE・BGM）」欄。タイムラインのカードの 💬 からも書けます。絵コンテPDFのセリフ欄とVコンテの字幕に出ます |
| 絵を別のカードへ | 「絵をコピー」→ 別のカードを開いて「絵を貼り付け」（⌘C／⌘Vでも可）。今の絵に重なります |

- 描いた絵は自動で保存され、マップとタイムラインのカードに小さく表示されます。
- iPadでApple Pencilを使うと、手のひらで誤って描かないように、そのあとは指では描けなくなります（ページを再読み込みすると元に戻ります）。

## PDFに書き出す

画面上の **「📄 PDF」** から、2つの形式を選べます。

- **絵コンテ用紙**：カット・画面・内容・セリフ・秒 の表（A4縦）。Vコンテの「シーン構成」の順に並びます。1ページのカット数は4〜6から選べます。
- **マインドマップ型**：マップ全体を1枚に収めた図。企画の説明やプレゼンに。

用紙は A4 と A3 から選べます。

## カメラワーク

カットごとに、基本的なカメラワークをつけられます。Vコンテの再生（とこれからのMP4書き出し）に反映されます。

| 種類 | 動き |
|---|---|
| PAN | 絵を拡大して、端から端へカメラが動く（← → ↑ ↓） |
| FOLLOW | 絵が流れ続ける（背景を引いて、キャラを追いかける感じ） |
| T.U | だんだん寄る（寄る位置を9か所から選べます） |
| T.B | 寄りからだんだん引く |
| F.I／F.O | 黒（または白）から出てくる／黒に消える。ほかの動きと一緒に使えます |

- 開き方：タイムラインのカードの **🎥**、Vコンテや描画パネルの「🎥 カメラ」。
- 設定パネルの上で、そのカットがくり返し再生されるので、見ながら選べます。
- 描画パネルには、カメラの **「始め」（青）と「終わり」（オレンジ）の枠** が出ます。映る範囲を意識して描けます。
- 「スロー」にすると、ゆっくり動き出してゆっくり止まります。
- F.I／F.O は最長3秒まで選べます。

### 長い絵（PAN・FOLLOW用）

描画パネルの **「用紙」** で、横長（×1.5／×2／×3）や縦長にできます。

- 横長の用紙で PAN にすると、絵を拡大せずに用紙の端から端までカメラが動きます。
- FOLLOW にすると、用紙をつなげて流し続けます。**右端と左端がつながるように描く** と、途切れずに流れます。
- 動きのないカットでも、カメラ設定の「映す位置」で用紙のどこを映すか選べます。
- 描画パネルの点線の枠が、画面に映る範囲です。

## 使い方（Vコンテ）

上の「Vコンテ」タブを押すと、タイムラインの順番と尺どおりに絵を再生します。

| やりたいこと | 操作 |
|---|---|
| 再生・一時停止 | 「▶ 再生」またはスペースキー |
| 1コマずつ送る | ← → |
| 前後のカットへ | ◀◀ ▶▶ または Shift+← → |
| 好きな位置へ | 下のバーをタップ・ドラッグ |
| くり返し再生 | 「⟲ ループ」 |
| 直したいカットを描く | 止めて「✎ このカットを描く」 |

- 左上にカット番号と時間、下にカードの文字が出ます。いらなければチェックを外してください。

**「剥がす」は削除ではありません。** 保留トレイに移るだけなので、いつでも戻せます。
気軽に貼ったり剥がしたりしてください。

## 作品の保存について（大事）

- 作品はブラウザの中に **自動で保存** されます（画面右上に「保存済み」と出ます）。
- **「💾 保存」**（⌘/Ctrl+S）で、作品を **zipファイル** に保存できます。
  - ブラウザの履歴やサイトデータを消すと、ブラウザの中の作品も消えます。**こまめに「💾 保存」でバックアップ** してください。
  - 別のパソコンやiPadに移すときも、このzipを使います。iPadでは「ファイル」アプリに保存されます。
  - zipの中には、作品のデータ（project.json）と、各カットの絵（PNG）が入っています。
- **「📁 プロジェクト」** で、
  - 新しいプロジェクトを作る
  - このブラウザにあるほかのプロジェクトを開く・複製する・削除する
  - 「ファイルから開く」で、保存したzipを読み込む（解凍しなくてOK）
- 右上が **赤や黄色の表示** になっているときは、自動保存がうまく効いていません。すぐ「💾 保存」でファイルに保存して、先生に知らせてください。
